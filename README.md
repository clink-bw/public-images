# public-images

Images for email and web demos, served from a public CDN. Everything here is public
and may be indexed: made-up brands and drawings only, never anything about a real
person or customer.

Link to a file through jsDelivr, pinned to a commit, so a sent email never changes:

```
https://cdn.jsdelivr.net/gh/clink-bw/public-images@<commit>/<path>
```

| Folder | What |
|---|---|
| `gogo/` | GOGO Coffee & Bakery, a made-up café brand: product drawings, 800px square PNG |

The drawings are generated from code; files here are outputs, not edited by hand.
